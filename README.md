Random Password Generator
Автор: Югова Ирина Александровна

Описание
Простое кроссплатформенное приложение с графическим интерфейсом для генерации случайных паролей. Позволяет настраивать длину пароля и выбирать используемые символы (цифры, буквы, спецсимволы). История сгенерированных паролей сохраняется в файл password_history.json.

Технологии
Python 3.x.
Tkinter (стандартная библиотека).
random.
json.
Инструкция по запуску
Установите Python (если не установлен).
Клонируйте репозиторий:
bash
Копировать
git clone https://github.com/[ваш_ник]/random-password-generator.git
cd random-password-generator
Запустите приложение:
bash
Копировать
python main.py
Используйте ползунок и чекбоксы для настройки параметров.
Нажмите «Сгенерировать пароль».
История паролей отображается в таблице.
Примеры использования
Генерация пароля из 16 символов с цифрами и буквами.
Генерация сложного пароля с использованием спецсимволов.
Просмотр последних 10 сгенерированных паролей в таблице.
